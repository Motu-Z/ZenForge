# Zenwik

AMD Ryzen 处理器轻量化本地调校工具。可调整核心电压（Curve Optimizer）、频率上限（FMax）与功耗墙（PPT / TDC / EDC / 温度墙），并基于 CPU Sets 自行绑定应用进程所用核心。

*使用前请确保本机已安装 .NET 10 Runtime 和 PawnIO。*

## 开始

双击 `Zenwik.exe`，同意 UAC 提权。本工具绿色无毒，若杀软误报请自行加白。

发布包是两个文件：`Zenwik.exe` 与 `WinIo32.dll`，**必须放在同一目录**。
后者是 SMU 库在 PawnIO 缺位时回退端口访问用的原生组件，它按文件名自己加载，塞不进单文件包里。

从旧版（`ZenForge`）升级：配置文件会自动从 `%APPDATA%\ZenForge\` 迁到 `%APPDATA%\Zenwik\`；
开机自启的计划任务改名为 `ZenwikAutoStart`，旧任务请到「任务计划程序」里手动删掉。

## 界面

- **调校**：Curve Optimizer 逐核偏移、功耗墙四项限制、FMax 频率上限设定。
- **调度**：按进程名将线程绑定至 CCD0、CCD1 或自定义掩码。
- **日志**：实时日志流。
- **设置**：主题、开机自启动行为、关闭与托盘行为等。

## 后台

自启通过计划任务赋予最高权限，不弹 UAC，移动程序位置后需重新勾选自启以修正路径。

静默自启时，无 UI 界面纯后台驻留。进程监听由 WMI 事件驱动，空闲时 0 CPU占用。若系统禁用了 Winmgmt（WMI）服务，会自动降级为每 3 秒轮询一次，此时会有少量常驻 CPU 占用及数秒绑定延迟。

由于 WPF 框架特性决定其一旦加载就无法彻底卸载，开启前台界面后内存占用将会略微提高；关闭界面仅能释放页面数据，框架内存差会保持到进程重启。

若关闭托盘图标且选择“关闭窗口后收进托盘”，进程将彻底静默运行（无托盘入口）。

托盘右键选择暂停绑核仅暂停监听行为，已绑定的进程不受影响。

## 排障

数据目录为 ``%APPDATA%\Zenwik\``，删除后即重置。

调校参数删除后不会自动恢复默认值，请写回默认值后再退出。

若启动程序后无窗口，可能是在加载 WPF 界面或已有实例运行。

若 SMU 读不到值，可能是 PawnIO 未正确安装，请查看日志中的探测结果。
