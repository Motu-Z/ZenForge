# 📚 ZenForge UI 设计规范与实现标准 (v1.0.2 Final)

> 基线版本：WPF / .NET 10 / 1.0.2
> 文档定位：所有 UI 代码必须严格遵循本规范。禁止发明新色值、新字号或随意写死尺寸。

---

## 0. 核心原则与基石效应

**基石效应**：任何版本迭代必须为下一版本打地基。严禁返工（如改了 UI 导致底层的定时器重写）。

**文本极简**：界面绝对禁止出现"说明性废话"（如"当前电源方案支持……"）。用户想了解功能请查阅 README。只保留短促的动词标签。

**响应式自适应**：不写死卡片高度，所有行高由内边距撑开。同屏并排控件必须等高。

---

## 1. 窗口与全局布局骨架

### 窗口特性
无边框模式（`WindowStyle="None"`）。

### 尺寸限制
默认 `1120 × 780`，最小 `920 × 600`。

### 拖拽与控制
- 顶部保留 **40px** 高度的隐形拖拽区（绑定 `DragMove`）。
- 右上角放置**最小化、最大化、关闭**按钮（自定义样式，悬停关闭按钮变红）。

### 侧边栏
- 宽度 **208px**。背景色 `#18181A`。
- 分三组，每组之间用 `Margin="0,20,0,20"` 的分割线隔开。
- 底部：左右分列 `中 / EN` 切换器 和 版本号（如 `v1.0.2`），字号 **L6**。

### 内容区
- 外边距统一为 `28, 6, 28, 24`。
- 必须包裹在 `ScrollViewer` 内。卡片间距 **16px**。

## 2. 色彩体系与视觉基准

### 2.1 基础结构色

| 角色 | 色值 |
|---|---|
| 窗口底 | `#121214` |
| 侧栏底 | `#18181A` |
| 卡片底 | `#08FFFFFF`（半透明叠加） |
| 卡片边框 | `#14FFFFFF`（1px） |

### 2.2 文本颜色层级（严禁全白铺满）

| 键 | 色值 | 典型搭配 | 用途 |
|---|---|---|---|
| `Text.Primary` | `#FFFFFF` | — | 主标题 / 标签 |
| `Text.Secondary` | 60% 白色 | L5 / 12px | 副标题 / 说明 |
| `Text.Meta` | 46% 白色 | L6 / 11px | 路径 / 版本 / 时间戳 |

### 2.3 控件交互色

**强调色**：`#38BDF8`。只用于边框、开关开启态、滑块的滑块。

**语义色（铁律区，禁止跟随强调色）**：

| 语义 | 色值 |
|---|---|
| 日志 Info（灰蓝） | `#A3B8CC` |
| 警告 Warn（黄） | `#F5D90A` |
| 错误 Error（红） | `#FF453A` |
| 危险操作按钮边框/文字 | `#FF453A` |

## 3. 字体阶梯与排版

**唯一字体族**：`Microsoft YaHei UI`；`Consolas`（用于数字和时间）。

| 层级 | 样式键 | 字号 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|---|
| L1 | `PageTitle` | 26 | Bold | Primary | 页面大标题 |
| L2 | `CardTitle` | 15 | SemiBold | Primary | 卡片标题 |
| L3 | `Numeric` | 16 | Bold | Primary | 核心数值（等宽） |
| L4 | `Label` | 13 | Medium | Primary | 控件标签、正文 |
| L5 | `Desc` | 12 | Normal | Secondary | 元数据、辅助说明 |
| L6 | `Meta` | 11 | Normal | Meta | 路径、时间戳、版本号 |

> 注：L2 必须比 L4 大 2px，防止视觉层级黏连。

## 4. 控件与组件规范

### 4.1 标准尺寸

- 所有常规输入框、下拉框、次要按钮：高度 **32px**，圆角 **6px**。
- 小按钮（如列表操作中的禁用/应用/删除）：高度 **26px**，`TextWrapping="NoWrap"`（强制不换行）。
- 卡片：圆角 **10px**，内边距 `20, 22`。

### 4.2 交互状态（所有控件必备）

| 状态 | 表现 |
|---|---|
| Hover | 背景变亮或边框提亮 |
| Active | 轻微缩放（0.96）或背景加深 |
| Disabled | 整块变灰或透明度降为 0.4 |

### 4.3 特殊组件细节

- **开关 (Toggle)**：尺寸 `36×20`，圆角 `10`。滑块 `16×16`，过渡动画 `150ms`。
- **滑块 (Slider)**：轨道高 `4`，圆角 `2`。滑块圆球 `16×16`。松手才提交写硬件，拖动中只更新数值显示。
- **卡片内部布局**：最后一行必须有 `Margin="0"` 消除尾巴，防止卡片底部多出 20px 空白。

## 5. 页面布局明细清单

### 5.1 调校页
- **CPU 卡片**：左侧型号+副行，右侧四个按钮（加载/保存/刷新/应用）。
- **CO 网格**：多列均分（基于实际核心数适配），等高等宽。
- **FMax 卡片**：标题在左，输入框和单位在右侧同行，无冗余说明文字。
- **电源与策略卡片**：三行（电源策略下拉、升频模式下拉、核心停放滑块+输入框）。

### 5.2 进程页
- **运行中进程**：表头列宽 `3:7`，行内含下拉框（掩码/优先级）。
- **已保存规则**：带数量 Pill 标签，底部操作按钮（禁用/应用/删除）强制单行显示。

### 5.3 配置页
- **场景自动切换卡片**：标题+右侧开关。
- **总体配置方案卡片**：列表包含方案名、描述、应用按钮。
- **规则库双列**：左右并排（调校规则 / 调度规则），严格等高。

### 5.4 通用页
- **样式卡片**：主题模式下拉、强调色下拉、自定义颜色行（色块+彩虹滑块+HEX 输入）。
- **诊断卡片**：导出日志按钮、SMU 自检按钮。
- **关于卡片**：居中显示版本号、GitHub 链接、MIT 协议。

### 5.5 行为页
- **启动卡片**：开机静默自启、自动应用调校。
- **后台卡片**：开启后台服务（总闸），下方缩进子选项（常驻调度、轻量模式、托盘图标）。
- **通知卡片**：出错时通知我（放在最底部）。

### 5.6 高级页
- **安全卡片**：设备防砖、智能休眠。
- **重置卡片**：停用全部功能、清除全部数据（红色按钮，极简文本）。

### 5.7 日志页
- **第一行**：左对齐三个带实心圆点的 Pill 徽章（信息/警告/错误），右对齐"详细日志"开关。
- **第二行**：左对齐搜索框，右对齐"暂停/清空/目录"按钮。
- **列表**：左侧带语义色竖条，时间戳为灰色。

## 6. WPF 工程约束与红线（必看）

1. **禁止使用系统白色默认控件**：输入框、下拉框、滚动条、ToolTip 必须通过 Style 全覆盖为深色。
2. **禁止跨字典引用**：`ControlTemplate` 内绝对禁止使用 `StaticResource` 跨字典引用 `App.xaml` 里的资源（会引发运行期崩溃），应改用 `DynamicResource` 或内联。
3. **后台零占用**：切换页面或窗口隐藏时，必须通过 `PageTimerManager` 挂起（Stop）UI 刷新定时器，确保 CPU 回落至 0%。
4. **列表更新必须增量**：禁止 `Clear()` + `Add`。必须开启 `VirtualizingPanel`，使用 `Move`/`Insert`/`Remove`。
5. **行状态数据驱动**：开启虚拟化回收后，禁止用代码修改行背景色，必须通过 `DataTrigger` 绑定 `IsSelected` 属性。
6. **UI 线程安全**：跨线程更新 `ObservableCollection` 必须通过 `Dispatcher.BeginInvoke`。
7. **无废话注释**：禁止写"// 赋值"这种注释，只写"// 必须在 UI 线程更新"这类底层原理注释。
